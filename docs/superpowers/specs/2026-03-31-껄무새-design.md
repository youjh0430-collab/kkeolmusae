# 껄무새 — 서비스 설계 문서

**작성일:** 2026-03-31  
**서비스명:** 껄무새  
**컨셉:** "살 껄~" 하는 앵무새 — 소비 대신 주식을 샀다면 지금 수익률이 얼마였을지 시뮬레이션하는 귀여운 금융 서비스

---

## 1. 서비스 개요

### 핵심 기능
"지난 X기간 동안 [소비 항목]을 안 하고 [주식]을 샀다면, 지금 수익률은?"을 계산해주는 시뮬레이션 서비스.

### 사용자 접근 정책
- **비로그인**: 시뮬레이션 1회 무료
- **로그인**: 무제한 시뮬레이션 + 히스토리 저장

---

## 2. 기술 스택

| 영역 | 기술 |
|------|------|
| 프론트엔드 | Next.js 14 (App Router) + TailwindCSS |
| 배포 | Vercel |
| 인증/DB | Supabase (PostgreSQL + Auth + Storage) |
| 주식 데이터 | yahoo-finance2 (npm) — Next.js API Route에서 호출 |
| TTS | Web Speech API (브라우저 내장, 무료) |
| 소셜 로그인 | Google + Kakao |

---

## 3. 핵심 기능 상세

### 3-1. 시뮬레이션 입력
- **소비 항목**: 인기 항목 추천 목록 (이름 + 가격 + 이모지) + 직접 입력 가능
- **기간**: 프리셋 (1주일 / 1개월 / 3개월 / 6개월 / 1년) + 직접 날짜 범위 입력
- **주식 선택**: 인기 주식 목록 (국내 TOP / 해외 TOP) + 종목명/티커 검색

### 3-2. 시뮬레이션 계산 로직
```
투자 가능 금액 = 소비 항목 단가 × 기간 내 횟수(일수 기반 추정)
매수 주가 = 기간 시작일 종가 (yahoo-finance2 historical data)
현재 주가 = 오늘 종가
수익률 = (현재 주가 - 매수 주가) / 매수 주가 × 100
수익금 = 투자 가능 금액 × (수익률 / 100)
```

### 3-3. 결과 화면
- 수익률 (%) + 수익금 (원)
- 주가 변동 차트 (Recharts)
- 껄무새 AI 코멘트 (수익률 구간별 고정 멘트)
- TTS 버튼 (Web Speech API로 코멘트 음성 출력)
- 결과 공유 카드 이미지 생성

### 3-4. 껄무새 코멘트 (TTS 연동)
| 수익률 구간 | 코멘트 예시 |
|------------|------------|
| +50% 이상 | "살껄~~ 살껄~~ 왜 안 샀어!! 🦜" |
| +10% ~ +50% | "쏠쏠했을텐데~ 아깝다 아깝다~" |
| -10% ~ +10% | "뭐... 그냥 그랬을 수도 있어~ 😅" |
| -10% 이하 | "오히려 다행이야~ 안 샀길 잘했어~ 🎉" |

### 3-5. 결과 공유
- HTML Canvas로 공유용 이미지 카드 생성
- Supabase Storage에 업로드 후 공유 URL 발급
- OG 태그 지원 (`/share/[id]`)

### 3-6. 히스토리 (로그인 유저)
- 로그인 유저의 시뮬레이션 결과 자동 저장
- `/history` 페이지에서 목록 조회

### 3-7. 후회 랭킹
- simulations 테이블 집계 기반
- 가장 많이 시뮬레이션된 주식 TOP 10
- 평균 수익률 기준 정렬
- 랜딩 페이지 하단 + `/ranking` 페이지

## 4. DB 스키마

### simulations
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | uuid | PK |
| user_id | uuid (nullable) | 비로그인 시 null |
| item_name | text | 소비 항목 이름 |
| item_price | integer | 항목 단가 (원) |
| period_start | date | 시뮬레이션 시작일 |
| period_end | date | 시뮬레이션 종료일 |
| stock_ticker | text | 종목 티커 (예: 005930.KS) |
| stock_name | text | 종목 이름 |
| return_rate | numeric | 수익률 (%) |
| profit_amount | numeric | 수익금 (원) |
| share_image_url | text (nullable) | 공유 카드 이미지 URL |
| created_at | timestamptz | 생성 시각 |

### popular_items
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | uuid | PK |
| name | text | 항목 이름 |
| price | integer | 기본 단가 (원) |
| emoji | text | 이모지 |
| category | text | 카테고리 |
| usage_count | integer | 사용 횟수 (추천 순 정렬용) |

### popular_stocks
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | uuid | PK |
| ticker | text | 야후 파이낸스 티커 |
| name_ko | text | 한국어 종목명 |
| market | text | KR / US |
| simulation_count | integer | 시뮬레이션 횟수 |
| avg_return_rate | numeric | 평균 수익률 |

---

## 5. 페이지 구성

| 경로 | 설명 |
|------|------|
| `/` | 랜딩 페이지 (히어로 + 예시 + 후회 랭킹 미리보기) |
| `/simulate` | 시뮬레이션 입력 (3단계 스텝) |
| `/result/[id]` | 결과 화면 (수익률 + 차트 + 껄무새 + 공유) |
| `/history` | 내 시뮬레이션 기록 (로그인 필요) |
| `/ranking` | 후회 랭킹 전체 |
| `/share/[id]` | 공유 카드 OG 페이지 |

---

## 6. 유저 플로우

### 비로그인
랜딩 → 시뮬레이션 입력 → 결과 확인 → (로그인 유도 CTA) → 공유 카드 (선택)

### 로그인
랜딩/대시보드 → 시뮬레이션 입력 (무제한) → 결과 확인 + 자동 저장 → 히스토리 누적 → 공유 카드 (선택)
